# Vector Sorting Lab — Incomplete Starter

**Status:** Incomplete academic artifact. The committed [VectorSorting.cpp](./VectorSorting.cpp) is the default Visual Studio “Hello World” program. It does not load the included CSV files, create a bid vector, or implement a sorting algorithm.

This repository should not currently be used as evidence of a completed sorting implementation. The [canonical CS-300 repository](https://github.com/mf0zz13-SNHU-School-Work/CS-300-Reflection) contains the completed course planner and data-structure analysis.

## What is present

- A Visual Studio C++ solution and project targeting the v143 toolset and Windows 10 SDK.
- Two eBid CSV datasets also used by the course's bid-management labs:
  - [eBid_Monthly_Sales.csv](./eBid_Monthly_Sales.csv)
  - [eBid_Monthly_Sales_Dec_2016.csv](./eBid_Monthly_Sales_Dec_2016.csv)
- The untouched console starter that prints **Hello World!**
- Tracked Visual Studio metadata and Debug/Release build output.

The datasets appear in the related SNHU course exercises. This repository does not contain additional provenance or a parser that uses them.

## Work needed

To become a meaningful vector-sorting lab, the project still needs:

1. A bid record model and CSV-loading path.
2. The sorting algorithms required by the course exercise.
3. A menu or command-line workflow that demonstrates and compares those algorithms.
4. Edge-case checks and repeatable tests.
5. Cleanup of generated IDE and build artifacts.

Those are source-code changes and have intentionally not been made as part of the README work.
